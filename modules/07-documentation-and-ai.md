# Lesson 7: Documentation and AI

## Learning Objectives

By the end of this lesson, students will be able to:

- Differentiate between policies and procedures
- Explain why security documentation must be continuously maintained
- Describe how AI can support documentation activities
- Identify the importance of human review for AI-generated documents

## Documentation in GRC and Security

Documentation is critical for GRC practitioners, security teams, auditors, and other employees.

It helps an organization explain:

- What rules apply
- What is expected from employees
- How systems are configured
- How tasks should be performed
- How to respond to incidents
- How to recover systems after a failure

## Policies and Procedures

A policy defines the overarching governance of an environment.

A procedure documents how to perform a specific task.

For example:

- A password policy defines password requirements.
- A password reset procedure explains the steps that support staff must follow.

## Documentation Must Stay Current

Policies and procedures are living and breathing documents.

If documentation is treated as a one-and-done activity, it can become stale and inaccurate.

Outdated documentation can create problems during:

- Audits
- Security incidents
- System recovery
- Employee training
- Daily operational work

## How AI Can Help

AI may help GRC and security teams improve documentation by:

- Creating first drafts of policies and procedures
- Suggesting improvements to existing documentation
- Summarizing technical changes
- Helping identify documentation that may need updates
- Creating recovery playbooks during system setup
- Improving the clarity and consistency of written content

If AI can recognize relevant changes in an environment, it may help teams update documentation more efficiently. If it cannot access the environment, it can still provide a useful starting point for writing.

## Recovery Playbooks

A recovery playbook is a documented plan for restoring a system after an incident, outage, or failure.

Creating a recovery playbook during system setup helps ensure that staff are not guessing during an emergency.

The playbook should describe the original configuration, recovery steps, required contacts, validation activities, and escalation process.

## Human Review Is Essential

AI-generated documentation must be reviewed by qualified people.

Security and GRC practitioners must verify that the documentation is:

- Accurate
- Current
- Appropriate for the organization
- Aligned with policies and legal requirements
- Clear enough for others to follow

## Key Takeaway

Documentation is critical for both GRC and security. AI can speed up drafting, improve consistency, and support updates, but people must validate the content and keep it aligned with the real environment.
